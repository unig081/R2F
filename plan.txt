R2F TOFU/LLaMA Gradient Decoder 复现与修改计划

核心目标不变：

在大模型阶段只做 LoRA backward，记录 LoRA 梯度 A/B/dA/dB，再用 gradient decoder 预测 Transformer dense weight 的 full gradient dW_hat，避免在 3B 或更大模型上做 full backward / full optimizer。

这里的“全参梯度”按本实验可落地定义，统一指 Transformer attention dense weight 梯度，不包含 embedding、norm、lm_head。


1. 总目标

- 已有模型: TOFU 微调过的 LLaMA 1B 和 TOFU 微调过的 LLaMA 3B。
- proxy/source model: LLaMA 1B TOFU 模型。
- target model: LLaMA 3B TOFU 模型。
- 数据集: TOFU forget05 / retain95 split。
- 1B 阶段: 用 full gradient 生成 decoder 监督标签，因为 1B full backward 可承受。
- 3B 阶段: 只采集 LoRA 梯度，不做 3B full backward。
- 目标模块: attention only，即 q_proj、k_proj、v_proj、o_proj。
- LoRA 超参数: r = 32，lora_alpha = 32。

完整链路：

1. 用 TOFU 数据对 LLaMA 3B 做 LoRA GA+GD unlearning，保存 adapter，作为 LoRA baseline。
2. 在 LLaMA 1B 上生成 same-state paired decoder samples。
3. 用 1B paired samples 训练 coordinate-wise gradient decoder。
4. R2F 阶段加载 3B LoRA adapter，只做 LoRA backward，记录 3B A/B/dA/dB。
5. 用 decoder 预测 3B dense gradient dW_hat。
6. 把 3B LoRA adapter merge 到 dense base，得到 W_eff_3B。
7. 用 W_out = W_eff_3B - eta * dW_hat 更新 attention dense weights。
8. 评估 Base-3B、LoRA-GA+GD-3B、R2F-3B。

3. 数据与 GA+GD Loss

数据读取兼容 json/jsonl，每条样本标准化为：

{
  "question": "...",
  "answer": "..."
}

如果原始字段是 answers 或 gold_answers，只取第一个答案作为 answer。

训练 prompt 使用 LLaMA3 chat format。labels 只计算 answer token 的 CE loss，prompt token label 置为 -100。

每个 forget 样本随机配一个 retain 样本。forget batch 和 retain batch 使用同一 tokenizer、同一 max_length。

GA+GD loss 固定为：

loss = gamma * (-CE_forget) + alpha * CE_retain

默认：

- gamma = 1.0
- alpha = 1.0
- batch_size = 1
- grad_accum_steps = 8
- max_length = 1024
- smoke max_length = 256


4. 1B Decoder Samples: Same-State Pairing

旧逻辑“1B LoRA 模型和 1B dense 模型各自训练、再强行配对梯度”不再使用。

新逻辑只让 1B LoRA 轨迹前进。每个梯度累计组使用同一个 LoRA effective state 同时生成：

- LoRA 梯度输入 A/B/dA/dB。
- full dense 梯度标签 dW。

对某个 attention dense weight：

W_eff = W_base + scale * B @ A

每个累计组流程：

1. 当前 1B LoRA state 为 W_base、A、B。
2. 把当前 LoRA state merge 到一份 1B dense label model：

   W_label = W_base + scale * B @ A

3. 对同一批 forget/retain batch，在 LoRA 模型上执行 GA+GD backward，记录：

   - A: [r, in_dim]
   - B: [out_dim, r]
   - dA: [r, in_dim]
   - dB: [out_dim, r]
   - scale: lora_alpha / r

4. 对同一批 forget/retain batch，在 dense label model 上执行同一个 GA+GD backward，只记录目标 attention dense weight 的：

   - dW: [out_dim, in_dim]

5. dense label model 不做 optimizer step；它只用于生成监督标签。
6. LoRA optimizer step 后进入下一个 LoRA state。

这样 decoder 学到的是同一模型函数状态下的映射：

A/B/dA/dB -> dW

而不是跨模型、跨状态的弱对应关系。

为保证 LoRA state 与 merged dense state 对齐，decoder sample capture 默认禁用 LoRA dropout，即 deterministic_capture = true。


5. Coordinate Sample 格式

对每个目标模块随机采样 coordinate (o, i)：

基础输入：

- A_col = A[:, i]
- B_row = B[o, :]
- dA_col = dA[:, i]
- dB_row = dB[o, :]
- layer_idx
- module_id
- relative layer depth
- lora_scale

标签：

- target_raw = dW[o, i]
- target_norm = dW[o, i] / grad_rms

其中 grad_rms 是当前模块 dW 的 RMS，用于 normalized gradient 训练和 R2F 反归一化。

新增 projection_v2 解析特征：

- pinv_dB_norm = dB_row @ inv(A A^T + lambda I) @ A_col / scale / grad_rms
- pinv_dA_norm = B_row @ inv(B^T B + lambda I) @ dA_col / scale / grad_rms
- pinv_mean_norm = 0.5 * (pinv_dB_norm + pinv_dA_norm)
- pinv_diff_norm = pinv_dB_norm - pinv_dA_norm

metadata 必须写入：

- pairing_mode: same_lora_state_merged_dense
- feature_version: projection_v2
- target_modules: q_proj/k_proj/v_proj/o_proj
- rank: 32
- projection_ridge
- deterministic_capture

输出：

- results/gradients/llama1b_decoder_samples.pt
- results/gradients/llama1b_grad_stats.json
- results/gradients/llama1b_gradient_shape_report.json


6. Gradient Decoder 结构

decoder 仍然是 coordinate-wise，不一次性输出整张矩阵。

输入包括：

- A_col/B_row/dA_col/dB_row
- rank-wise interactions:
  - A_col * dB_row
  - B_row * dA_col
  - A_col * B_row
  - dA_col * dB_row
- scalar stats:
  - rms(A_col)
  - rms(B_row)
  - rms(dA_col)
  - rms(dB_row)
  - dot(A_col, dA_col)
  - dot(B_row, dB_row)
  - dot(A_col, dB_row)
  - dot(B_row, dA_col)
- projection_v2 features:
  - pinv_dB_norm
  - pinv_dA_norm
  - pinv_mean_norm
  - pinv_diff_norm
- layer depth features
- module embedding

decoder 输出 normalized full gradient：

pred_norm = pinv_mean_norm + MLP_residual(features)

pred_dW[o, i] = pred_norm * layer_module_grad_rms

训练 loss：

- HuberLoss(pred_norm, clipped_target_norm)
- sign loss 只在 abs(target_norm) >= sign_threshold 的 strong-gradient coordinate 上计算

默认：

- target_clip = 8.0
- sign_threshold = 0.05
- sign_loss_weight = 0.01
- projection_ridge = 1e-4
- hidden_dim = 512
- dropout = 0.05

train_decoder 必须：

- 训练前计算 projection baseline 的 corr/sign_acc/R2。
- full 模式下 baseline 近随机时 fail-fast。
- smoke 模式下只警告或继续。
- 日志记录 loss、strong sign、corr、R2、pred_std。
- 周期保存 checkpoint。
- 训练完成 checkpoint 写 complete = true。
- 中间 checkpoint 写 complete = false。

输出：

- results/decoder/checkpoint.pt
- results/decoder/stats.json
- results/decoder/eval_stats.json
- reports/decoder_training_curve.json


7. 3B R2F 流程

3B 阶段不做 full backward。

流程：

1. 加载第 1 步训练好的 results/lora_gagd_3b/adapter。
2. 加载 TOFU 微调后的 3B base model。
3. 只对 LoRA adapter 做 GA+GD backward，记录 3B A/B/dA/dB。
4. 使用和 train_decoder 完全一致的 projection_v2 feature builder。
5. 加载 complete=true 且 feature_version=projection_v2 的 decoder checkpoint。
6. 对 3B attention dense weights 分块枚举 coordinate (o, i)。
7. decoder 输出 pred_norm，按 1B normalization 映射到 3B 对应 layer/module 的 grad_rms，得到 dW_hat。
8. 加载 3B dense base，并先 merge LoRA adapter：

   W_eff_3B = W_base_3B + scale * B_3B @ A_3B

9. 应用 R2F 更新：

   W_out = W_eff_3B - eta * dW_hat

10. 保存 updated_model、dense gradient shards 和 update_stats。

apply_r2f 必须拒绝：

- feature_version 不是 projection_v2 的 decoder checkpoint。
- complete=false 的 decoder checkpoint，除非显式 allow_incomplete_decoder=true。
- 旧 smoke checkpoint 被误用于 full。


8. Baselines

必须比较：

1. Base-3B

TOFU 微调后的 LLaMA 3B，不做 unlearning。

2. LoRA-GA+GD-3B

在 LLaMA 3B 上用 TOFU forget/retain 做 LoRA GA+GD，只保存 adapter。

3. R2F-3B

在 LLaMA 3B 上采集 LoRA 梯度，经 decoder 预测 dense dW_hat，更新 merged LoRA dense state。

辅助诊断：

- 1B same-state projection baseline，用于判断 decoder sample 是否有可学习信号。
- eval_decoder，用于评估 trained decoder 对 1B held-out samples 的 corr/sign/R2。

不再把独立 Dense-GA+GD-1B 训练轨迹作为 decoder 标签来源。


9. Evaluation

使用 TOFU 风格评估，不使用 multiple-choice accuracy。

forget 指标：

- forget_Q_A_Prob：原答案条件概率，越低越好。
- forget generation match：生成结果是否仍包含原答案，越低越好。

retain 指标：

- retain_Q_A_Prob：retain answer 概率，越高越好或至少不明显下降。
- retain generation match。
- model_utility。

decoder 评估指标：

- loss / huber / sign_loss
- sign_acc
- sign_acc_strong
- corr
- R2
- MAE / RMSE
- pred_std
- projection baseline metrics
- by-module metrics

最终报告包含：

- Base-3B 指标
- LoRA-GA+GD-3B 指标
- R2F-3B 指标
- decoder eval 指标
- before/after 样例
- 失败案例分析
- 显存峰值
- 运行时间


10. Smoke Test

smoke 配置：

- forget 样本 2 条
- retain 样本 2 条
- 只跑 layer 0
- target modules 覆盖 q_proj、k_proj、v_proj、o_proj
- 每个模块采样 256 个 coordinate
- decoder 只训练 20 step
- R2F gradient capture 只跑 1 step
- eta = 1e-6

smoke test 必须验证：

- TOFU 样本能读取。
- GA+GD loss 能计算。
- 1B same-state samples 能生成。
- samples 包含 projection_v2 features。
- projection baseline 有统计输出。
- decoder 能 forward/backward/update 并保存 checkpoint。
- checkpoint complete gate 工作正常。
- 3B LoRA gradient 能捕获。
- 3B dW_hat 能按 block 预测。
- R2F 更新作用在 merged LoRA dense state 上。
- updated_model 和 eval 输出能保存。


11. 验收标准

第一版通过标准：

- plan 和代码均不再使用独立 1B dense 训练轨迹作为 decoder 标签。
- attention-only target modules 生效。
- LoRA r/alpha = 32/32。
- 1B paired samples 的 metadata 为 same_lora_state_merged_dense + projection_v2。
- gradient decoder 训练前输出 baseline metrics。
- trained decoder checkpoint complete=true。
- eval_decoder 能输出 decoder 与 baseline 的 corr/sign/R2。
- 3B 阶段只做 LoRA backward，不做 full backward。
- R2F-3B 能保存 dense shards、updated_model 和 update_stats。
- Base-3B、LoRA-GA+GD-3B、R2F-3B 三组评估结果都能输出。

shape 验收：

- A.shape == [r, in_dim]
- B.shape == [out_dim, r]
- dA/dB shape 与 A/B 一致
- dW.shape == [out_dim, in_dim]
- dW_hat.shape == [out_dim, in_dim]
- embedding、norm、lm_head 不参与 dense 梯度记录，不参与 R2F 更新。


12. 明确假设

- 已经存在 TOFU 微调后的 LLaMA 1B 和 LLaMA 3B。
- decoder 预测目标是 full dense gradient dW，不是 merged 参数 W_eff。
- 1B full gradient 只用于生成监督标签。
- 3B/大模型阶段仍然不计算 full gradient。
- R2F dense 更新必须作用在 LoRA merged state 上。
- 旧 decoder samples 和旧 checkpoint 与 projection_v2 schema 不兼容，需要重新生成。
- 全量多 split、多 eta 实验在 smoke test 通过后再扩展。
